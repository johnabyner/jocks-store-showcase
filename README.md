---

## 🎯 Sobre o Projeto

O **Jocks Store Showcase** é uma vitrine virtual criada do zero sem o uso de frameworks. O objetivo principal deste projeto é consolidar boas práticas de desenvolvimento web moderno, garantindo uma interface fluida, semântica e interativa.

A aplicação simula a página inicial de uma loja de calçados ("Jocks"), utilizando técnicas avançadas de posicionamento e eventos dinâmicos no navegador.

---

## ⚡ Destaques Técnicos

- 🎨 **Layout Moderno (Grid & Flexbox):** Estruturação de componentes complexos, barras de navegação alinhadas e vitrines de produtos dinâmicas.
- 🎬 **Animações Nativas:** Uso avançado de `@keyframes` com ritmos alternados (`alternate` e `alternate-reverse`) para criar um efeito orgânico de flutuação nos produtos.
- 🧠 **JavaScript Eficiente:** Implementação de um carrossel de imagens contínuo utilizando Arrays e o padrão de **Event Delegation** para otimização de performance.
- 📱 **Design Responsivo:** Interface adaptável para dispositivos móveis através de *Media Queries*, reestruturando automaticamente a grade de produtos.
- 📌 **Controle de Fluxo (Positioning):** Domínio de comportamentos de tela com elementos `sticky` (menu de navegação) e `fixed` (botões flutuantes).

---

## 🖥️ Funcionalidades

- 🛒 Vitrine de produtos animada (Best Sellers).
- 🔄 Carrossel interativo de GIFs na seção principal (Hero Section).
- 🧭 Barra de navegação responsiva e fixada no topo.
- 🤖 Botão de ação flutuante (simulação de chatbot/suporte).
- ✨ Efeitos visuais e feedbacks de interação (Hover, Transitions e Transforms).
